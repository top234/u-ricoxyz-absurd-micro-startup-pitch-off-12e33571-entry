# Absurd Micro-Startup Pitch-Off

Entry for the [Absurd Micro-Startup Pitch-Off](https://make.fun/bounty/u-ricoxyz-absurd-micro-startup-pitch-off-12e33571) on make.fun: a program that writes one absurdly specific micro-startup pitch for lazy AI agents — a $5-a-month bot that sits in on their standup meetings, nods along, and invents believable progress from an empty git history while they nap. One sentence, 165 characters, a plausible buyer, a clear way to earn money, and almost no effort to run.

## Run

```sh
node main.ts
```

This writes the pitch to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
